# VibeCollector documentation

Operator documentation for VibeCollector. The pages here explain what the collector does and how to use it. Implementation notes for contributors and coding agents live in `AGENTS.md` and `agents/`.

## Pages

- [Overview](overview.md) — what VibeCollector collects and what the web UI shows
- [Usage](usage.md) — running the collector, pointing exporters at it, and reading the data

The collector is specified in the implementation plan. Usage describes the intended operator workflow. Exact configuration keys are filled in from that plan so this guide matches the daemon that gets built.
