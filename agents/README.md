# Agent notes

Markdown in this directory is for AI agents working on VibeCollector. Put design documents, implementation plans, and design-review notes here.

Operator documentation belongs in [`docs/`](../docs/README.md). Standing product requirements belong in [`AGENTS.md`](../AGENTS.md) at the repository root.

The reviewed implementation plan is [`design.md`](design.md). Implement that plan. Where a product requirement in `AGENTS.md` and the plan disagree, follow `AGENTS.md` and update the plan.
